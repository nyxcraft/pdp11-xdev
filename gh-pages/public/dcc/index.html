pdp11-dcc

The decompile driver: disassembles a compiled object (or whole archive / executable) back to per-object assembler files and recompiles them — the round-trip harness behind the das corpus results.

The decompile driver: disassembles a compiled object (or whole archive / executable) back to per-object assembler files and recompiles them — the round-trip harness behind the das corpus results.

pdp11-dcc file.{o,s,a} | a.out
  • Splits multi-object inputs into one .s per member, handles stripped binaries, and keeps an incremental symbol map across runs.
  • Finds its tools like cc does: runs the sibling pdp11-das from its own directory, falling back to $PATH.

Build and test

make          # builds ../../bin/pdp11-dcc
make check    # exercised by the das/dcc oracle sweeps
